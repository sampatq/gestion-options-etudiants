# Gestion Options Étudiants

Java REST API project for managing options and students with Jersey and JAX-RS.

## Run

Deploy the `Gestion_Options_Etudiants:war exploded` artifact to Tomcat, then open:

`http://localhost:8080/Gestion_Options_Etudiants_war_exploded/rest/options`
